# 一键批量关闭 2345 图片（2345 看图王）

Windows 下被 2345 看图王（2345PicViewer）的守护进程反复拉起、关不掉？两个小脚本，双击即可强制结束全部相关进程与守护服务。

## 文件说明

| 文件 | 作用 |
|---|---|
| `一键关闭2345图片_启动器.vbs` | 静默启动器（无黑框）。先停 `2345Pic` 守护服务，再依次 taskkill 所有相关进程，1 秒后补刀一次防止自重启。 |
| `一键关闭2345图片_无确认.cmd` | 命令行版本，自动申请管理员权限，先停服务并把服务改为手动启动，再循环 5 轮 taskkill，最后 PowerShell 兜底。 |

## 使用方法

1. 下载这两个文件到本地任意目录。
2. **推荐**：双击 `一键关闭2345图片_启动器.vbs`，无窗口直接执行，完成后弹窗提示 Done。
3. 想看到执行过程或需要更强力的清理：右键 `一键关闭2345图片_无确认.cmd` → 以管理员身份运行（脚本也会自动尝试提权）。

## 会结束哪些进程 / 服务

- 服务：`2345Pic`（守护服务，先停止并在 cmd 版中改为手动启动）
- 进程：`2345PicViewer.exe`、`2345PicWorker.exe`、`PicService.exe`、`2345PicHelper.exe`、`2345PicUpdater.exe`

> 注意：这只是**关闭当前正在运行的 2345 看图王**，并不卸载它。如果需要彻底卸载，仍请走控制面板或官方卸载流程。
